# Development

## Prerequisites

- Windows 10/11, .NET 10 SDK (`dotnet --version` ≥ 10.0)
- Optional: Claude Code logged in, to see real data

## Common tasks

```powershell
dotnet build                                   # whole solution
dotnet test                                    # all unit tests (no network, no real credentials)
dotnet run --project src/Pace                  # run the tray app
dotnet publish src/Pace -c Release -o publish  # framework-dependent Release build
dotnet publish src/Pace -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o publish
```

Only one instance runs at a time. Running Pace again opens the existing popover, so stop the running one (tray → Quit Pace) before debugging a new build.

## App icon

`src/Pace/Assets/Pace.ico` is generated by the same drawing code the tray uses:

```powershell
dotnet run --project src/Pace -- --export-icon src/Pace/Assets/Pace.ico
```

Re-run it only if you change `Tray.DrawGauge`.

## Tests

`tests/Pace.Tests` covers:

| Area | What's tested |
|---|---|
| Parsing | Real response shape (`Fixtures/usage.json`), missing/null sections, entries with null percent or kind, bad dates, limit titles |
| Service | Request URL/method/headers, missing credentials, expired token (no request sent), 401/429/500/302, network failure, malformed body, token never in messages |
| Credentials | Valid file, missing `claudeAiOauth`, empty token, invalid JSON, missing file |
| Countdown | Null, past, exact, minutes, hours, < 1 day, ≥ 1 day; severity thresholds |
| Refresh | Concurrent refreshes → one request, failure keeps last data and marks stale, unexpected exception, plan/tray text |

The tests never call the network or read the real credentials file.

## Manual checks before a release

1. First run: tray icon appears, popover shows data, a `Pace` value exists under `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
2. Click the tray icon → popover opens next to it. Click Refresh inside it → it stays put. Click outside or press Esc → it closes. Click the icon while it's open → it closes.
3. Refresh button → glyph spins, "Updated" time changes.
4. Disconnect the network → refresh shows "Can't reach api.anthropic.com…", the old numbers stay, and the tooltip ends in ⚠.
5. Rename `.credentials.json` → "No Claude Code login found". Restore it → the next refresh recovers.
6. Toggle "Launch at startup" and check Task Manager → Startup apps. Toggle "Show % in tray icon" → the icon switches between number and gauge.
7. Switch Windows to light mode, reopen the popover → light palette.

## Repository hygiene

`.gitignore` excludes build output and any `.credentials.json`. Never paste real tokens into fixtures or issues: `Fixtures/usage.json` contains only usage numbers, no secrets.
